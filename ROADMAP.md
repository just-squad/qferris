# **Roadmap для QFerris**  
### **Цель:** Постепенное развитие с фокусом на **минимально жизнеспособный продукт (MVP)** → **полноценный API-клиент** → **конкурент лидерам**.  

## **🔹 Этап 0: Подготовка (1-2 недели)**  
**Задачи:**  
- [ ] Определить **ядро функционала** (что будет в MVP).  
- [ ] Выбрать **технологический стек** (окончательно).  
- [ ] Настроить **CI/CD** (GitHub Actions/GitLab CI).  
- [ ] Создать **репозиторий** + документация (README, CONTRIBUTING).  

**Результат:** Готовность к разработке.  

---

## **🔹 Этап 1: MVP (2-3 месяца)**  
**Цель:** Рабочий прототип с **базовыми HTTP/Grpc-запросами** и **сохранением коллекций**.  

### **1.1. Базовый GUI (1 месяц)**  
- [ ] Окно с **вкладками** (как в Postman).  
- [ ] Поля для **URL, метода, заголовков, тела**.  
- [ ] Кнопка **"Send"** + вывод ответа.  
- [ ] Поддержка **тёмной/светлой темы**.  

### **1.2. HTTP/Grpc-клиент (1 месяц)**  
- [ ] **REST-запросы** (`reqwest`).  
- [ ] **Grpc-запросы** (`tonic` + загрузка `.proto`).  
- [ ] Поддержка **кук, заголовков, параметров**.  

### **1.3. Сохранение коллекций (1 месяц)**  
- [ ] **Локальное хранение** (SQLite).  
- [ ] **Импорт/экспорт** (JSON).  
- [ ] Группировка запросов в **папки**.  

**Результат:** MVP, которым можно пользоваться локально.  

---

## **🔹 Этап 2: Расширение функционала (3-6 месяцев)**  
**Цель:** Добавить **фичи уровня Insomnia**.  

### **2.1. Улучшение UX**  
- [ ] **Автодополнение** URL/заголовков.  
- [ ] **История запросов**.  
- [ ] **Переменные окружения** (как `{{base_url}}`).  

### **2.2. Продвинутые запросы**  
- [ ] **GraphQL** (через `graphql-client`).  
- [ ] **WebSocket** (через `tokio-tungstenite`).  
- [ ] **Мокирование ответов** (для тестирования).  

### **2.3. Синхронизация**  
- [ ] **Git-интеграция** (`git2-rs`).  
- [ ] **Облачное сохранение** (свой бекенд или интеграция с GitHub/GitLab).  

**Результат:** Приложение уровня **Insomnia**.  

---

## **🔹 Этап 3: Конкуренция с Postman (6-12 месяцев)**  
**Цель:** **Финальные полировки** + **уникальные фичи**.  

### **3.1. Плагины и экосистема**  
- [ ] **WASM-плагины** (`wasmtime`).  
- [ ] **Магазин плагинов** (например, для тестирования API).  

### **3.2. Производительность**  
- [ ] **Бенчмарки** (сравнение с Postman/Insomnia).  
- [ ] Оптимизация **памяти/CPU**.  

### **3.3. Дополнительные фичи**  
- [ ] **Командная работа** (shared-коллекции).  
- [ ] **Документирование API** (экспорт в OpenAPI).  
- [ ] **Тесты/скрипты** (на Rust?).  

**Результат:** **Конкурент Postman** с упором на **производительность** и **Rust-экосистему**.  

---

## **🔹 Этап 4: Масштабирование (12+ месяцев)**  
**Цель:** Рост сообщества и экосистемы.  
- [ ] **Публичный бета-тест**.  
- [ ] Поддержка **плагинов от сообщества**.  
- [ ] Интеграция с **IDE (VS Code, JetBrains)**.
